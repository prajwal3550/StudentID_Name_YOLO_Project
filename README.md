# YOLO Object Detection Project

## Project Title

YOLO Object Detection using YOLOv8

## Short Description

This project uses the YOLOv8 deep learning model to detect objects in an input image. The model identifies objects and draws bounding boxes with class labels around detected items.

## Tools and Libraries Used

* Python
* YOLOv8 (Ultralytics)
* OpenCV
* PyTorch
* NumPy
* Matplotlib

## How to Run the Code

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the program:

   ```bash
   python main.py
   ```

3. The detected image will be saved as:

   ```text
   output_result.png
   ```

## Input Image Description

The input image contains everyday objects such as people, cars, bicycles, or other common items used for object detection testing.

## Output Result Explanation

The YOLO model detects objects in the image and draws bounding boxes around them. Each box includes the object class name and confidence score.
